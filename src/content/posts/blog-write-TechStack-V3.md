这个博客是纯静态的——Astro + Svelte,跑在 Vercel 上。以前发文章、改友链、加项目,都得本地开编辑器改文件再 push。后来我给它加了个 `/write` 写作台,文章和日记能在线写了,但导航栏里「我的 / 关于 / 其他」那一堆板块,还是得回去摸代码。

这一版把它们**全搬进了写作台**。现在一个后台,9 个内容板块加一个开关,整站都能在线改。

## 写作台里有什么

| 模块 | 能干嘛 |
|---|---|
| ✍️ 文章 | 增删改,还能翻历史文章列表 |
| 📔 日记 | 增删改 |
| 👤 关于 | Markdown 正文直接编辑 |
| 🔗 友链 | 站名、链接、头像、简介、标签 |
| 🛠️ 项目 | 名称、描述、封面、分类、技术栈、链接 |
| 🧠 技能 | 名称、图标、等级、经验、颜色 |
| 🕰️ 时间线 | 标题、类型、日期、组织、技能 |
| 💻 设备 | 按品牌分组,设备增删改 |
| 📷 相册 | 新建、编辑、删除,图片上传/删除 |
| 🎛️ 板块开关 | 一键隐藏某个板块,导航跟着消失 |

## 数据是怎么从代码里抠出来的

这些板块的数据,原本都硬编码在 `.ts` 文件里——友链是 `friends.ts` 里一个数组,想加一条得改代码。我照着日记的老办法,把数据抽到同目录的 JSON:

```text
friends.ts   →  friends.json   +  friends.ts（只留类型和工具函数）
projects.ts  →  projects.json
skills.ts    →  skills.json
timeline.ts  →  timeline.json
devices.ts   →  devices.json
```

数据进了 JSON,在线编辑就只剩「读写一个文件」这一件事。页面那边 `import` 路径一个没动,原来怎么读现在还怎么读。

字段我都做成了文本框,不放下拉——有固定取值的字段,就在 placeholder 里提示可选值。想填新分类也填得进,不会被下拉框卡死。

## 板块开关:隐藏,不是删除

有时候某个板块暂时不想放出来,比如时间线还没内容、相册还没整理。勾掉开关就完事,它做两件事:

1. **页面 404**——关掉的板块页面自动重定向。
2. **导航入口跟着消失**——这一条是这次补的。原来导航不认开关,关了页面但菜单里还挂着,点进去 404,挺别扭。

> 顺带一个小细节:如果某个下拉菜单里的子项全被藏了,那个下拉菜单整个也不见了。

## 一些取舍

- **番剧没做**——它的数据是构建时从 Bangumi / Bilibili 拉的,在线改了下次构建就覆盖,做了白做。
- **删除文章/日记不清理图片**——同一张图可能被多篇引用,不敢盲目删。相册是例外,删图删相册都是真删。

## 说说这套东西怎么搭的

安全上还是那套老规矩:凭证只放 Vercel 环境变量,浏览器永远碰不到;后端有路径白名单,只放行该放行的文件。前端一个 Svelte 编辑器,后端几个 Serverless 函数,中间就 8 个接口,数得过来,也够用。

整站内容收进一个后台之后,发东西就顺了:打开 `/write/`,输密码,想改哪点哪,保存完等一分钟就上线。不用再摸 `.ts` 文件。

这个思路不一定适合所有人——多作者协作或者内容敏感,就得考虑 OAuth 或独立后端了。但如果你也是一个人折腾静态博客,想让自己写东西稍微体面点,这套东西可以参考。
